# Weather Wondors

A clone of the **Apple Weather** app built using **HTML**, **CSS**, and **JavaScript** — with a twist.  
This project demonstrates API integration and a custom design to test and showcase my frontend skills.

## Features

- Fetches real-time weather data using the **OpenWeatherMap API**  
- Displays current temperature, weather conditions, and other key metrics  
- Clean UI inspired by Apple Weather but with a unique style  
- Responsive design to look good on different screen sizes  

## How It Works

1. The app sends a request to OpenWeatherMap API (via `script_api.js`).  
2. It retrieves weather information (temperature, description, etc.) for the specified location.  
3. The data is displayed dynamically in the UI using JavaScript.  
4. Users can navigate through different screens (`screen2.html`, `screen3.html`) for more detailed weather or UI effects.
